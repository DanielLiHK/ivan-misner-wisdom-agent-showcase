# Public Release Notes

## v1.1.1

This release presents an independent, source-grounded wisdom application experiment about publicly documented teachings associated with Dr. Ivan Misner. It explores whether AI can organise, connect, and apply a body of wisdom without impersonating the person behind it.

It retains `Soul`, `Role`, `Knowledge`, and `Thinking Frameworks` as a structured wisdom architecture for organising principles, knowledge, reasoning patterns, and application boundaries. These files do not claim to reconstruct Dr. Ivan Misner's personality, private thoughts, or inner mind.

The release is intentionally focused on readable outcomes and high-level methodology. It is not a complete account of Dr. Ivan Misner's work, an official product, or a finished chatbot.

## Review principles

The project distinguishes documented source material, cross-source synthesis, and context-specific application. Theory pages retain limitations instead of presenting every concept as equally established. Public summaries use source links so readers can inspect context directly.

## Scope boundary

The showcase explains the result and the principles used to organise it. The underlying research workspace, unpublished materials, and implementation details are outside the scope of this public presentation.

`ivan-misner-wisdom-agent-showcase`
