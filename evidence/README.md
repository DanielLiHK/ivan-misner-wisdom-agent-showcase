# Evidence Sample / 證據樣本

`EVIDENCE_SAMPLE.json` is a small public-safe sample intended to demonstrate traceability. It is not the complete corpus and does not include raw webpage text, pending records, reviewer identity, API metadata, or internal decisions.

每條 sample 只展示 concept、短 summary、來源及 status。`Needs research` 或未審核資料不會被包裝成 confirmed fact。

Use the source URL to inspect context directly. The project author reserves the right to correct summaries when a source changes or a later review identifies a problem.
