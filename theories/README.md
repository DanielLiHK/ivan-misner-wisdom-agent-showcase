# Theories

Each theory page separates a minimal documented summary from interpretation, possible persona placement, limitations, and source links. The status labels describe this project's evidence state; they do not indicate official endorsement.


The release intentionally treats the six theories differently. Four have enough first-party material for a cautious foundation but still have gaps. The Three Rs and The 3rd Paradigm remain limited to conservative summaries and are not expanded into full reasoning systems.
