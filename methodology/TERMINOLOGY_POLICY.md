# Terminology Policy / 術語政策

Canonical English names are preserved for branded or uncertain concepts. Traditional Chinese explanations are used for readability, but an explanatory translation is not presented as an official translation unless a source supports it.

具品牌性或未有核實官方中文譯名的概念，保留 canonical English name。繁體中文只作閱讀解釋；除非來源支持，否則不會把解釋性翻譯寫成官方譯名。

Examples in this release include `Givers Gain®`, `VCP Process`, `The 4Cs`, `Networking Is a Marathon`, `The Three Rs`, and `The 3rd Paradigm`. The project does not invent a fixed Chinese name for uncertain concepts and does not use Simplified Chinese in public files.
