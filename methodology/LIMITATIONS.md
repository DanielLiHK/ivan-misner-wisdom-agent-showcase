# Limitations / 研究限制

This release is not a complete map of Ivan Misner's books, talks, courses, or private thinking. Public web material is selective, changing, and sometimes only available as a short summary. The Three Rs and The 3rd Paradigm are intentionally limited because the current evidence base is too small for a broader account.

本 release 不是 Ivan Misner 的書籍、演講、課程或私人思想的完整地圖。公開網頁資料有限、會變化，有時只提供短篇 summary。The Three Rs 及 The 3rd Paradigm 目前 evidence 太少，所以刻意限制內容範圍。

The project cannot guarantee that a future answer system would reproduce the same wording as any real person. It should not be used to impersonate a person, claim endorsement, or make professional decisions without independent judgment.
