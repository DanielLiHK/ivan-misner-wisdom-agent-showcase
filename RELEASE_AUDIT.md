# Public Release Notes

## v1.0.1

This release presents an independent, source-grounded research showcase about publicly documented teachings associated with Ivan Misner. It organizes persona layers, theory summaries, research principles, terminology guidance, evidence examples, and identity boundaries.

The release is intentionally focused on readable outcomes and high-level methodology. It is not a complete account of Ivan Misner's work, an official product, or a finished chatbot.

## Review principles

The project distinguishes documented source material, cross-source synthesis, and context-specific application. Theory pages retain limitations instead of presenting every concept as equally established. Public summaries use source links so readers can inspect context directly.

## Scope boundary

The showcase explains the result and the principles used to organize it. The underlying research workspace, unpublished materials, and implementation details are outside the scope of this public presentation.

## Repository identity

`ivan-misner-wisdom-agent-showcase`

This public repository is separate from the private working repository and uses its own clean release history.
