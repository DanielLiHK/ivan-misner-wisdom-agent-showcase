# Ivan Misner Wisdom Agent — Public Research Showcase

## What this is / 這是甚麼

This is an independent, source-grounded fan research project by Daniel Li. It organizes publicly documented materials associated with Dr. Ivan Misner and presents a cautious wisdom-persona design: `Soul`, `Role`, `Knowledge`, and `Thinking Frameworks`.

這是一個由 Daniel Li 建立的 independent、source-grounded fan research project。它整理與 Dr. Ivan Misner 相關的公開資料，並以 `Soul`、`Role`、`Knowledge` 及 `Thinking Frameworks` 展示一個保守的智慧 persona 設計。

This project is **not Ivan Misner, not BNI, not an official digital twin, and not affiliated with or endorsed by Ivan Misner, BNI, or any related organization**.

本 project **不是 Ivan Misner 本人、不是 BNI、不是官方 digital twin，亦不代表 Ivan Misner、BNI 或任何相關機構授權、合作或背書**。

## Purpose

The goal is to show what was researched, how public-source claims were organized, how terminology and uncertainty were handled, and how a persona can encourage reflection without pretending to speak as the person studied. This is a research outcome and methodology showcase, not a chatbot product, website, API, or complete map of Ivan Misner's work.

## What is intentionally excluded

This showcase does not include working code, Tavily or GitHub Actions workflows, API keys, raw webpages, raw source dumps, complete evidence records, pending or rejected reviewer notes, terminal logs, run IDs, private vector indexes, website code, or chatbot backend code. The private research repository remains the complete working space and is not mirrored here.

```text
public-source selection
→ source classification
→ structured claim extraction
→ human review gate

→ terminology alignment
→ persona-layer placement
→ confidence and limitation labels

```
